# Notes Application

A modern, beginner-friendly Notes Application built using HTML, CSS, and JavaScript.  
This project demonstrates frontend development, REST API integration, and client-side data persistence using localStorage.

---

## Features

- Create new notes
- Delete notes
- Mark notes as completed
- Persistent storage using browser localStorage
- Initial data fetched from a REST API
- Responsive, card-based modern UI

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- REST API (JSONPlaceholder)
- Browser LocalStorage
- Git & GitHub

---

---

## How to Run the Project

1. Clone the repository
2. Open the project folder
3. Open `index.html` in a web browser

No additional setup required.
